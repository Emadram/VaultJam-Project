# Documentation Directory

This directory contains all project documentation.

## Directory Structure

- **Design/**: Game design documents, concept art, and design decisions
- **Technical/**: Technical specifications, architecture diagrams, and API documentation
- **Tutorials/**: Guides and tutorials for team members

## Guidelines

- Keep documentation up-to-date with code changes
- Use Markdown format for easy readability
- Include diagrams where helpful
- Document important decisions and their rationale
